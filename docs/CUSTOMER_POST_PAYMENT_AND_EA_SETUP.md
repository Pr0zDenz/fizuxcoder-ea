# Buyer Post-Payment, Installation, and Activation Guide

## Post-payment message shown to customers

> **Payment received — complete your secure setup.** Sign in to the FizuxCoder Customer Portal using the same e-mail address used at ToyyibPay checkout. In **Your eligible downloads**, select your product, enter the ToyyibPay settlement or invoice reference, and choose **Verify receipt**. When your product card shows **Access active**, bind the numeric MT5 account that will run the EA, then download the package files from that card. The download link is protected and temporary.

Customers should not share their portal login, settlement reference, downloaded EA files, or MT5 account credentials. Trading involves substantial risk; test every configuration on a demo account before considering live trading.

## Common MT5 installation steps

| Step | What the customer does |
|---|---|
| 1 | Download the listed `.ex5` files only from the active portal product card. |
| 2 | In MT5, choose **File → Open Data Folder**. |
| 3 | Open `MQL5\Experts` and copy the main EA `.ex5` file there. Copy indicator/dashboard/calendar files to `MQL5\Indicators` unless the product-specific instructions state otherwise. |
| 4 | Restart MT5 or right-click **Navigator → Refresh**. |
| 5 | Confirm the EA and required indicators appear in Navigator. |
| 6 | Drag the main EA onto the intended chart. Enable **Algo Trading** only after reviewing the EA inputs and risk settings. |
| 7 | Check **Experts** and **Journal** for any missing-file, licence, or initialization messages. |

> MT5 folder structures can differ by broker installation. **File → Open Data Folder** is the reliable way to reach the terminal’s active data directory.

## Troubleshooting

| Symptom | First check |
|---|---|
| Product card does not appear | Confirm the customer is signed in with the same checkout e-mail, then verify the correct ToyyibPay settlement reference. |
| Download button is missing | Select **Refresh access**. The product must show **Access active** and have package files published by the administrator. |
| MT5 binding fails | Reconfirm the numeric MT5 account. If changing account, use **Replace account** from the same product card. |
| EA does not appear in Navigator | Confirm the file is in the active terminal data folder and restart or refresh Navigator. |
| EA shows a licence or authorization error | Confirm the portal product card is active and bound to the account running the EA; then check the MT5 Experts tab. |
